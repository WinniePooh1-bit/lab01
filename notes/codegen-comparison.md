# Codegen ба гараар бичсэн тестийн харьцуулалт

Энэ тэмдэглэлийг Codegen-ийг өөрийн компьютерт ажиллуулсны дараа бодит ажиглалтаар гүйцээнэ.

## Турших команд

```bash
npx playwright codegen https://www.saucedemo.com/
```

Browser дээр нэвтэрч, бүтээгдэхүүний жагсаалт руу орж, нэг барааг сагсанд нэмнэ. Codegen-ээс гарсан кодыг `tests/saucedemo.spec.ts` файлтай харьцуул.

## Харьцуулах зүйлс

| Ажиглалт | Codegen-ийн гаргасан код | Энэ төслийн тест |
|---|---|---|
| Нэвтрэх талбарын locator | Локал туршилтын дараа бөглөнө | `getByPlaceholder('Username')`, `getByPlaceholder('Password')` |
| Login товч | Локал туршилтын дараа бөглөнө | `getByRole('button', { name: 'Login' })` |
| Cart үйлдэл | Локал туршилтын дараа бөглөнө | `getByTestId('add-to-cart-sauce-labs-backpack')` |
| Assertion | Локал туршилтын дараа бөглөнө | `expect(...).toBeVisible()`, `toHaveText()`, `toHaveURL()` |

## Дүгнэлтийн асуултууд

1. Codegen аль locator-уудыг сонгосон бэ?
2. Үүсгэсэн кодод шаардлагагүй алхам эсвэл давхардал байсан уу?
3. Гараар бичсэн тестэд ямар assertion, helper, cleanup нэмсэн бэ?
4. Эцсийн кодонд ямар өөрчлөлт оруулсан бэ?

**Тэмдэглэл:** Codegen-ийн бодит гаралтыг үзээгүй байж үр дүнг таамгаар бөглөж болохгүй.
