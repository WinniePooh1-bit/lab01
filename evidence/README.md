# Локал ажиллуулалтын нотолгоо

Энэ хавтаст зөвхөн өөрийн компьютер дээр авсан бодит нотолгоог байрлуулна.

Санал болгож буй файлууд:

- `01-node-npm-versions.png` — `node --version` болон `npm --version` гаралт.
- `02-playwright-tests.png` — `npx playwright test` командын бүрэн гаралт.
- `03-html-report.png` — локал HTML report-ийн browser screenshot.
- `04-trace-viewer.png` — Trace Viewer-ийн алхам ба DOM snapshot харагдаж буй screenshot.
- `05-codegen.png` — Codegen ашиглан browser дээр үйлдэл бичүүлсэн бодит screenshot.

Хуурамч зураг, өөр компьютерийн хувилбарын гаралт, эсвэл ажиллуулаагүй тестийн тайлан бүү оруул. Тестийн бодит HTML тайланг төслийн үндсэн хавтаст үүсгэнэ; түүнийг commit хийх эсэхийг багшийн шаардлагаар шийд.
